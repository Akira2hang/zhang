# 灵魂拷问

一个整蛊互动页面(index.html,单文件、零依赖,离线也能打开)。

打开后显示:

> **白煜睿是不是最帅的?**

- 点「**是**」:前 5 次点击正常缩小(仍可点中),「不是」越变越大;
- 第 6 次起,**每点一次「是」,它就跳到屏幕随机位置跑一次**(保持可点击大小,不自动乱跑);
- 一旦点了「**不是**」,弹窗显示:**白煜睿真恶心!**

## 使用

- 直接双击 `index.html` 即可体验;
- 想发链接给朋友,把 `index.html` 部署到任意静态托管
  (GitHub Pages、Vercel、Netlify 等),再把链接发出去。

## 说明

- 纯 HTML/CSS/JS,无任何外部依赖,单文件即完整页面;
- 「是」每次点击缩小到 78%,「不是」放大到 122%,放大有上限(72px);
- 点「不是」后弹窗出现,「再来一次」按钮可刷新重玩。
